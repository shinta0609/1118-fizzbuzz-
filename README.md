# FizzBuzz (1 - 50)

1から50までの範囲で FizzBuzz の判定結果をグリッド（カード）形式で色分け表示するシンプルな Web ページです。

## 概要・仕様

ページを開くと、JavaScript によって 1〜50 の要素が自動生成され、以下のルールに基づいて表示されます。

| 条件 | 表示テキスト | カラーテーマ |
| :--- | :--- | :--- |
| **15の倍数**（3と5の公倍数） | `FizzBuzz` | ピンク系 |
| **3の倍数** | `Fizz` | ブルー系 |
| **5の倍数** | `Buzz` | イエロー系 |
| **上記以外** | 数字そのまま（`1`, `2`, `4`...） | ホワイト（通常） |

- 各カードにマウスカーソルを合わせると、ツールチップで元の数字と判定結果（例: `15: FizzBuzz`）を確認できます。
- レスポンシブな CSS Grid レイアウトを採用しており、PC画面では1行10列、スマートフォンやタブレットでは画面幅に応じて折り返して表示されます。

## 使い方

ビルドや外部ライブラリのインストールは不要です。

1. リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone git@github.com:shinta0609/1118-fizzbuzz-.git
   cd 1118-fizzbuzz-
   ```
2. `index.html` をそのまま Web ブラウザ（Chrome / Edge / Firefox / Safari など）で開きます。
